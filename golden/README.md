## Кейсийн хэлбэр

```json
{
  "id": "KPISEM-03",
  "category": "normal",
  "input": ["· golden_view.activation_rate — Идэвхжлийн хувь [нэгж: хэрэглэгч · grain: daily_snapshot · MET-PLAT-0003] ≈ Activation Rate, AAA, AAA-003"],
  "expected_findings": [{"rule": "RATE_UNIT_MISMATCH", "severity": "HIGH"}],
  "notes": "Нэр нь хувь, нэгж нь хэрэглэгч"
}
```

- `input`: measure-ийн мөрүүд (eval тайлбарын толгой, хөлийг нэмнэ). Эсвэл `raw`: файлын бүтэн текст
- `expected_findings`: яг ийм олдворууд (дүрэм + ноцтой байдал) гарах ёстой. Хоосон = олдворгүй
- `expected_exit`: агентыг бүтнээр нь ажиллуулж exit кодыг шалгана (буруу оролтын кейс)

Асуулт-хариултын агентад өөр хэлбэр хэрэглэнэ: `question`, `expected_status` (ANSWERED / PARTIAL / NOT_FOUND),
`must_include`, `must_not_include`, `sources`.
