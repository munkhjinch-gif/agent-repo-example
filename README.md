## Энэ агент юу хийдэг вэ

Манай байгууллагын KPI-ууд (жишээ нь «чанаргүй зээлийн хувь», «зээлийн багц») NetData системд бүртгэлтэй байдаг.
Тэнд KPI бүрийн нэр, хэмжих нэгж (хувь, төгрөг, ширхэг г.м.), код бичигдсэн байдаг. Тэдгээрийн дунд **алдаа,
зөрүү, давхардал** гарсан байж болно.

Агент энэ жагсаалтыг уншиж, сэжигтэй зүйлийг олоод **KPI-ийн эзэнд тавих асуулт** болгон тайлан гаргана.
Жишээ нь:

| Агентын олсон зүйл | Эзэнд тавих асуулт |
|---|---|
| KPI-ийн нэгж бичигдээгүй | «Энэ үзүүлэлтийн нэгж юу вэ?» |
| Нэр нь «...хувь» мөртлөө нэгж нь төгрөг | «Хувь уу, тоо уу? Аль нь буруу вэ?» |
| KPI-ийн код байхгүй | «Энэ үзүүлэлтийн код аль нь вэ?» |
| Ижил нэртэй хоёр өөр KPI байна | «Давхардал уу, эсвэл нэрэнд нь ялгаа нэмэх үү?» |
| Англи нэр нь ижил, монгол нэр нь өөр | «Нэг үзүүлэлт үү, хоёр уу?» |
| Нэг бүлгийн KPI-ууд өөр өөр ангилалд бүртгэгдсэн | «Аль ангилал нь зөв бэ?» |
| Нэр нь утгагүй код мэт (жишээ: `_fin_017_s2`) | «Утга заасан нэр өгөх үү?» |
| Өдөр бүрийн бус өөр давтамжаар бүртгэгдсэн | «Давтамж нь зөв үү?» |

Олдвор бүрд ач холбогдлын түвшин байна: **HIGH** (заавал шалгах), **MEDIUM**, **LOW**.

### Агент юу хийдэггүй вэ

- **Юу ч өөрчилдөггүй.** Зөвхөн уншаад тайлан гаргана. Засварыг KPI-ийн эзэн болон дата платформын баг хийнэ.
- **Шийдвэр гаргадаггүй.** Олдвор бүр «алдаа» гэсэн дүгнэлт биш, зөвхөн асуулт. Эцсийн шийдвэрийг хүн гаргана.
- **Хиймэл оюун (LLM) ашигладаггүй.** Тодорхой дүрмээр шалгадаг тул нэг оролтод үргэлж ижил хариу гаргана.

Дэлгэрэнгүй тодорхойлолт: [AGENT.md](AGENT.md).

## Хэрхэн ажиллуулах вэ

Энэ хэсэг нь агентыг өөрийн компьютер дээр туршиж үзэх инженерт зориулсан.

```sh
# 1. Агентыг ажиллуулах: KPI-ийн жагсаалт (.txt файл) байгаа хавтсыг зааж өгнө
INPUT_ATTACHMENTS_DIR=<хавтасны зам> python3 agent/run.py

# 2. Агентын чанарыг шалгах: бэлдсэн 30 жишээ кейсээр туршина
python3 eval/run_eval.py

# 3. Автомат тест ажиллуулах
python3 -m pytest
```

> **Windows дээр:** `python3`-ийн оронд `py` гэж бичнэ. Хэрэв консолд үсэг эвдэрч алдаа гарвал эхлээд
> `set PYTHONUTF8=1` (Git Bash дээр `export PYTHONUTF8=1`) гэж ажиллуулна.

Агентын үр дүн `out/` хавтсанд хоёр файлаар гарна: уншихад зориулсан тайлан (`.md`) ба Excel/Sheets-ээр нээх хүснэгт
(`.csv`).

**Чанарын шаардлага:** 30 жишээ кейсийн дор хаяж 90%-ийг зөв хийх ёстой. Өмнөх хувилбараас 2-оос дээш хувиар
муудвал шинэ хувилбарыг гаргахгүй.
